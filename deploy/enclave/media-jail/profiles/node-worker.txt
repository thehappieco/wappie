# node-worker: the syscall allowlist of every worker in the table (workers.rs:
# image, pdf and office, each /usr/local/bin/node on aarch64, musl,
# node:22-alpine). Everything here is granted UNCONDITIONALLY; the
# argument-filtered calls (socket and socketpair AF_UNIX only, clone without
# namespace flags, ioctl to a tiny request set, prctl name/VMA only), execve,
# and the io_uring and clone3 ENOSYS shims are added by seccomp.rs and must NOT
# appear below (profile.rs rejects a reserved name).
#
# Derived, not guessed (docs/mcp-enclave.md §16.6): the first group is exactly
# what the workers made over the whole §16.13 corpus, traced inside the jail
# with deploy/enclave/jailcheck/trace-profile.sh (strace -ff outside, only
# the job's processes after the exec of node). The second group is the reviewed
# reserve: paths the corpus on the test kernel does not reach but a worker
# can, each with its reason. A syscall missing here is a seccomp kill (exit
# 159, parser_failed), never a bypass, and check-image.sh --jail fails the
# build on one. Every addition is reviewed by the lead.
#
# aarch64 has no open/stat/poll/dup2/fork/pipe/mkdir/rename/unlink/access, only
# the *at and the newer forms, so only those appear here.

# --- reserve ---
# Returning from any handled signal (V8's WebAssembly trap handler, Node's own
# handlers), and the kernel restarting a call a signal interrupted.
rt_sigreturn
restart_syscall
# abort() (V8's heap limit, a failed check): musl raises SIGABRT with tkill.
# The worker is its PID namespace's init, which ignores a SIGABRT it sends
# itself, so musl then crashes on purpose and the job ends by SIGSEGV (139):
# a crash, never mistaken for a seccomp kill (159), which only a gap in this
# list can cause.
tkill
# Time: the test kernel's vDSO answers these without a syscall; the 4.14 blob's
# falls back to one for the clocks it lacks, and a sleep always is one.
clock_gettime
gettimeofday
nanosleep
clock_nanosleep
# V8's spinning locks back off with it, likelier on the enclave's one vCPU.
sched_yield
# libuv's stat when statx is unavailable.
newfstatat
# libuv writes a stream's queued chunks with one writev.
writev
