# Clock probe results, 2026-11-21

The fault-injection probe (`README.md`, plan section 5) was run on a separate
c7g.large parent (decision D2). It used Amazon Linux 2023 arm64 and
nitro-cli 1.5.3, with the enclave in debug mode, 1 vCPU and 1536 MiB. The
enclave kernel was 4.14.256-209.484.amzn2.aarch64. The instance was launched
for the probe and terminated after it, from 2026-11-20 23:54:57Z to
2026-11-21 03:39:01Z. The production parent was not used.

**Verdict: every scenario passes.** P0 needs no fallback, and the constants
marked "settled by P0" stay as they are.

The reader's code (`clock.mjs`, `health.mjs`, `nsm-timefeed`, chrony) is the
same in all four commits. Only the probe harness changed between runs.

In the second run KMS was down from S9's last unblock onward, because of
harness bug 1. S7, S5 and S6 ran after that point, but none of their checks
reads KMS: they test the NSM helper, chronyd and the ledger. Their results
therefore stand.

### Harness bugs found and fixed (never in the reader)

1. **The KMS "hold" kept vsock 8000 bound after the unblock.**
   - **Cause.** `control.py` closed the holder's listening socket while its
     accept thread was blocked on it. On AF_VSOCK, `shutdown()` does not wake
     that `accept()` either. The listener therefore stayed bound until the
     control server exited.
   - **Effect.** The parent's `nitro-enclaves-vsock-proxy` failed to bind on
     restart and reached systemd's start limit.
   - **Fix (abe20d7, then 4e46a17).** The holder runs in a child process,
     and the unblock kills it. The unblock then counts as done only when `ss`
     shows the unit's own main process listening on vsock 8000, on two looks
     a second apart. A unit in a crash loop is "active" for an instant, so
     `is-active` alone is not enough.
2. **The answer to `parent restore` was lost.**
   - **Cause.** The runner's `socat -t 5` closed the connection 5 s after
     sending the request. A restore sleeps 5 s before `chronyc makestep`, so
     its answer arrived after the close.
   - **Effect.** S8 recorded a null answer for its two restore phases. Every
     clock check in those phases passed.
   - **Fix (575f359).** socat waits for the answer as long as the request's
     own timeout.
